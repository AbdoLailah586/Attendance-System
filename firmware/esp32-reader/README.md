# قارئ الحضور RC522 وESP32 مع Bluetooth

Firmware **1.4.0** يستخدم RC522 ‏13.56MHz والصفارة وليدات الحضور وRefresh والانصراف. أُزيلت الشاشة من الكود والتوصيل بناءً على طلب المستخدم. النتيجة تظهر في الموقع وتشخيص USB.

- [التوصيل والرفع والاختبار](MANUAL-SETUP.md).
- [تشغيل المنصة وربط الكروت](OPERATOR-GUIDE.md).
- [توصيل الصفارة والليدات](BUZZER-LEDS.md).
- [اختبار متابعة iTAG وحدودها](BLE-TRACKING.md).

متابعة Bluetooth تجريبية: اتصال GATT وإعادة اتصال تلقائية، مع رصد الإعلانات وقراءة البطارية القياسية إذا كانت متاحة. الرصد يثبت وجود الجهاز المحمول فقط؛ لا يقدم إحداثيات GPS ولا يثبت وجود صاحبه يقينًا.

LittleFS يحتفظ بطابوري NFC وBluetooth منفصلين حتى ACK من النسخة المنشورة. التتبع المرتبط بموظف يبدأ داخل جلسة حضور الكارت وينتهي عند الانصراف أو الحد المعروف. تشخيص USB المؤقت لا يزيد عن 30 دقيقة ولا يستمر بعد إعادة التشغيل.

تغيير Wi-Fi عبر configure-readers.cmd لا يحتاج رفع الكود مرة أخرى. مفاتيح القارئات وكلمات المرور خارج المستودع. RDM6300 ‏125kHz غير مستخدم.
